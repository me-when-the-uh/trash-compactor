# GUI Mode

Launch with no arguments and a window opens.

## Launch Path

1. No directory argument means GUI.
2. A short CPU benchmark runs. If the machine is too slow, LZX is disabled by default.
3. The executable is a GUI-subsystem build. Windows never allocates a console window. The GUI opens without a competing terminal. Launched from a terminal with CLI arguments, the program attaches to that terminal instead.
4. The window stays open until it is closed.

If the GUI library is missing from a frozen executable, startup fails with a rebuild message.

## User Flows

### Folder analysis and compression

1. Choose a folder (or use the folder picker).
2. Adjust settings: minimum savings %, LZX disable, HDD mode (auto-suggested on a spinning disk: single worker, discovery order), binary vs decimal size labels, and excluded folders.
3. Press **Analyse** to run the streaming scan pipeline.
4. Review projected savings and the scan/entropy timing footer. DirectStorage games are left out of the estimate and listed as a notice on the analysis page.
5. Press **Compress** to execute the planned batches.

### Quick compression (1-click targets)

Quick compression reuses the same target list as CLI one-click mode. It analyses each existing target directory in sequence, then compresses where worthwhile.

When running as Administrator, an optional **Compress Windows binaries (CompactOS)** checkbox starts CompactOS in the background. Progress shows in the window. No extra console.

## Progress and Feedback

The GUI progress bar moves through approximate phases:

- Walk / scan (indeterminate until check phase begins)
- Per-file eligibility checks
- Entropy sampling
- Compression batches (a batch-start status line is shown while `compact.exe` is running a group of files)

Status text and the timing footer report walk rate and check rate separately.

Scan and compress run on a background thread. The window stays usable. Progress is batched. The bar and status catch up a few times a second. Intermediate frames can be dropped. Pause, Stop, warnings, CompactOS status, and exclusion edits still show up as they happen. The bar can show a completed state at the end of a phase.

## Internationalization

Locale strings come from `locales/*.json` at startup. Labels, buttons, settings help, and timing messages all go through that table.

Those files live at the repository root and are bundled into frozen builds.

## Settings Notices

The Settings page includes a Defender / real-time antivirus notice: AV software rescans reads and newly compressed files, which can significantly slow first-run compression on large trees.

Excluded folders are edited on the same page. The list is stored next to the incompressible cache and is not cleared by Reset to recommended. Protected system directories cannot be added.
