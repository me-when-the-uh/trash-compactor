# One-Click Mode

One-click mode automates the compression of high-impact directories and system files. It combines heuristic target selection with the standard compression pipeline.

## Target Resolution

Candidate directories come from environment variables.

It scans `ProgramFiles` and `ProgramFiles(x86)` to target installed applications. It also includes the current user's `AppData`, `Downloads`, and `Documents` directories (`%USERPROFILE%`), plus `%ProgramData%` when present. Paths are normalized to remove duplicates and verified to exist before they are added to the queue. User exclusions apply inside each target. DirectStorage games found under those trees are skipped per target, the same as in a normal scan.

## System Compression

Windows CompactOS compression can run alongside the file-level operations. CLI 1-click starts `compact.exe /compactos:always` in the background. Scan and entropy analysis continue in parallel.

CompactOS requires Administrator privileges and is opt-in: pass `--compactos-always` to enable it. On an interactive CLI the user is prompted before it starts, whereas on a non-interactive console (e.g. launched from Task Scheduler, or a redirected `.bat` / `.ps1` script) the flag is a no-op. GUI quick compression exposes an optional CompactOS checkbox instead.

## Execution Pipeline

The process runs in four stages.

### 1. Performance Benchmarking
A short CPU benchmark runs first. If it does not finish in 0.25 seconds, LZX is disabled for the session.

### 2. Entropy Analysis
The program performs an entropy dry-run analysis on all targets. This step calculates projected savings and identifies compressible data without modifying files.

### 3. User Intervention
A 300-second countdown pauses execution, allowing the user to review the dry-run statistics and proceed with compression or cancel the operation.

### 4. Compression
The program processes the targets using the standard compression logic described in [Compression Process](2.%20compression%20process.md).
